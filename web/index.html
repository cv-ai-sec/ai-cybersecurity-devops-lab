AI Cybersecurity DevOps Lab

A local, air-gapped multi-agent training lab for AI-driven DevSecOps — sandboxed inspection, an AI-assisted vulnerability→remediation pipeline, and active-defense simulation, all running against a local model.

Purpose

Hands-on fluency in AI-assisted DevOps security — deployment automation, log telemetry, vulnerability scanning, and gated auto-remediation — using only local, open-weight models and permissively-licensed tooling. No cloud API, no telemetry, nothing leaves this machine.

What this demonstrates

STEP 1 — SANDBOX BOUNDARY

Untrusted log content is inspected inside a disposable, network-isolated Docker container — no network, read-only root, dropped capabilities — before an LLM ever summarizes it.

STEP 2 — AI-DRIVEN PIPELINE

Monitor → Patcher → Validator: a vulnerability scan gets triaged by a local LLM, a fix gets proposed, and nothing executes without a deterministic policy check plus human approval.

STEP 3 — ACTIVE DEFENSE

A simulated traffic generator vs. a defensive swarm that blocks IPs and rotates mock credentials in response — the detect → decide → act → log loop, fully local.
